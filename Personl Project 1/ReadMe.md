Ive made a RNG type game my compsci1 personal project. This game uses functions methods and loops to generate random numbers to start the RNG game. I added Upgrades and even a leaderboard to make the game more fun and competitive. 
I use C# as my programming language and Visual Studio as my IDE. The game is designed to be simple yet engaging, allowing players to test their luck and strategy.
Ive used if statements for the looping type of game and to have special conditions for each runthough with a few special senerios that can occure if a number is generated or if a player rolls a range of numbers.
Ive also implemented a scoring system that rewards players based on their performance, encouraging them to improve their skills and climb the leaderboard. 
The game has menus for upgrades and many options for replayabity. 
The game features a user-friendly interface, making it easy for players to navigate and enjoy the experience.
Overall, this project has allowed me to apply my programming knowledge in a practical way while creating an entertaining game for others to enjoy.
